# Stacks.js + Angular Starter

Demonstrates wallet connect/disconnect with `@stacks/connect`, displaying the connected STX address, and calling a Clarity contract function (`stx_callContract`) on testnet.

## Getting started

```bash
npm install
npm start    # dev server on http://localhost:4200/
npm run build
```

Stacks.js docs: https://docs.hiro.so/stacks.js
